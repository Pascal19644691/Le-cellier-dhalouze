LE CELLIER D'HALOUZE — SITE WEB (PREMIÈRE VERSION)

Fichier principal : index.html

Pour voir le site :
- Ouvrez index.html dans un navigateur.
- Une connexion internet est nécessaire pour charger les photos distantes.

Le site est responsive (ordinateur, tablette, téléphone) et ne contient pas de publicité.
Le bouton de contact renvoie actuellement vers l'annonce Clévacances : aucun formulaire indépendant ni système de réservation n'est encore configuré.

Pour publier gratuitement :
1. Créez un compte GitHub sur https://github.com/
2. Créez un dépôt public, par exemple cellier-halouze.
3. Ajoutez index.html à la racine du dépôt.
4. Dans Settings > Pages, choisissez Deploy from a branch, puis la branche main et le dossier /(root).
5. GitHub affichera l'adresse publique du site après activation.

À vérifier avant publication :
- Les URL des photos Clévacances peuvent nécessiter un ajustement ; elles sont chargées depuis le site source.
- La rubrique historique comprend maintenant les pistes de recherche sur 1589, la famille Peschard et les troubles religieux. Les détails restent explicitement présentés comme des pistes à confirmer par les archives.
- Ajouter les mentions légales et une politique de confidentialité si des outils de mesure d'audience ou un formulaire sont ajoutés.
